# Empayar Niaga

Permainan simulasi pemilik perniagaan berlatarkan Malaysia. Mulakan dengan modal RM0.01 hingga RM10,000, pilih struktur SSM (Enterprise, Perkongsian, PLT, Sdn. Bhd.) dan salah satu daripada 13 industri, kemudian bina empayar anda sehingga tersenarai di Bursa Malaysia.

*A Malaysian business owner simulator. Available in Bahasa Melayu and English.*

## Cara bermain

Buka `index.html` dalam pelayar, atau main terus di GitHub Pages:
`https://<nama-pengguna>.github.io/<nama-repo>/`

- Satu fail HTML sahaja, tiada pemasangan.
- Permainan disimpan dalam pelayar (localStorage). Gunakan **Simpan → Muat turun fail simpanan** untuk sandaran atau untuk berpindah peranti.
- Tukar bahasa dengan butang **BM | EN** di bahagian atas.

## Ciri utama

- 13 industri dengan cara berniaga tersendiri (pelanggan datang sendiri, jualan dalam talian, pitching projek, B2B, keahlian, tempahan, mesin layan diri)
- 15 misi wajib, 40+ krisis dan drama pekerja berasaskan Akta Kerja 1955
- Agensi kreatif dengan krew produksi, projek besar (iklan, program TV, drama, filem) dan kerjasama stesen TV
- Cukai individu dan korporat, penukaran entiti SSM dan IPO Bursa Malaysia

> Nota: Angka yuran, cukai dan undang-undang dipermudahkan untuk permainan. Bukan nasihat kewangan atau undang-undang.
